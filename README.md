### Работа с IP-камерами по протоколу ONVIF

#### Постановка задачи
* Современные камеры в основном предлагают управление через своё облако (нестабильно, блокировки с обеих сторон)
* Потребовалось обеспечить видеонаблюдение объекта без привязки к облакам
* На части объектов нет проводного интернета, а мобильный - в режиме "белые списки"
* Решение - на объект устанавливается компьютер с python-скриптом, 
  отправляющим изображение/видео в Телеграм/MAX-чат. 

#### Возможности

* Работа с камерой через мессенджеры (Telegram/MAX и т.п.)
  * Управление PTZ сообщение в чате с кнопками ниже: "Влево/Вправо/Вверх/Вниз", "Сделать снимок/Видео"
  * Скрншот/видео по запросу
  * Включение/выключение детекции движения
* Обработка события "Детекция движения" - автоматическая отправка видео (с заданным периодом ДО события)
* Некоторые китайские камеры не поддерживают снятие скриншотов - берём первый кадр из RTSP-потока

#### Установка

* apt install python3.10-venv
* cd /opt
* git clone ssh://git@git.hrendel.ru:222/mihmig/onvif.git
* python3 -m venv .venv
* source .venv/bin/activate
* pip3 install -r requirements.txt

#### Запуск
``` bash
cd /opt/onvif

PYTHONPATH=. python3 worker_max.py camera-1
```
#### Обнаружение незнакомой камеры:
``` bash
cd /opt/onvif

PYTHONPATH=. python3 detect.py http://192.168.1.227:8899/ -u user -p password 
```
